Boolean Algebra Basics

Boolean algebra works with two values: 0 (False) and 1 (True).

AND

AND (·)

Output is 1 only when all inputs are 1.

Y = A · B
OR

OR (+)

Output is 1 when at least one input is 1.

Y = A + B
NOT

NOT (')

Inverts the input: 0 becomes 1 and 1 becomes 0.

Y = A'
LAW

De Morgan's Laws

Useful for transforming and simplifying logic expressions.

(A·B)' = A' + B'

Important Boolean Laws

IdentityA + 0 = A
A · 1 = A
Null / DominationA + 1 = 1
A · 0 = 0
IdempotentA + A = A
A · A = A
ComplementA + A' = 1
A · A' = 0
AbsorptionA + A·B = A
A(A + B) = A
De Morgan(A+B)' = A'·B'
(A·B)' = A'+B'
